# Tonalore branding

Tonalore is the rebranded native Android product identity for this fork of Auxio. The product keeps Music as a first-class experience and adds Audiobooks as a separate mode built on the same local-first playback foundation.

The primary visual direction is a waveform folded into an open book, using deep ink navy, warm amber, and muted teal. The launcher and Android Auto vectors are intentionally simple so they remain recognizable at small sizes and under Android adaptive-icon masks.

The application ID and provider authorities remain unchanged in the initial rebrand for installation and data compatibility. A future package migration must be treated as a separate release-engineering project.

This project is derived from [OxygenCobalt/Auxio](https://github.com/OxygenCobalt/Auxio) and retains the original GPLv3 license, copyright notices, and upstream attribution. The generated icon concepts in this directory are design references for the native vector implementation.
