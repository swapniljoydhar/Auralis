# Audiobook UX Evidence

## Supplied Auralis detail screen

The supplied `Bury Our Bones in the Midnight Soil` detail screen shows a collage cover made from unrelated books, a reported total of six chapters, and a mini-player for the unrelated `A Crane Among Wolves`. This confirms that the current directory-only grouping is collapsing separate local books into one catalog entry. The secondary control below **Start** renders as a filled button with no visible label; its label color currently matches the filled primary surface.

## Supplied Voice playback reference

The reference playback screen uses a focused hierarchy: one title, one cover, the active chapter selector, one progress slider, and three primary transport controls. The Auralis audiobook player should retain book-specific actions while reducing visual density toward this hierarchy.

## Supplied launcher and mode-hub screens

The launcher and mode-hub screenshots show a checkerboard square inside the Auralis mark. The checkerboard is rendered by the bitmap itself, so a corrected icon must use an opaque, full-bleed square background rather than a graphic that contains a transparency-preview pattern.
